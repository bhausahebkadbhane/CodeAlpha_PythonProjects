## 📌 Project Overview
This repository contains all the projects completed as part of the CodeAlpha Python Programming Internship.  
The internship focused on building strong fundamentals in Python, problem-solving, and real-world applications.
This project is a collection of Python-based mini applications developed during the CodeAlpha Internship. Each task focuses on solving real-world problems using core Python concepts.

The Hangman Game demonstrates logic building and user interaction through a word guessing game. The Stock Portfolio Tracker helps users calculate their total investment using predefined stock prices, showcasing the use of dictionaries and file handling.

The Task Automation script simplifies repetitive tasks such as moving files and extracting useful data like email addresses using Python modules like os, shutil, and re. The Basic Chatbot simulates a conversation using predefined responses, helping understand control flow and functions.

Overall, this project highlights practical implementation of Python programming including loops, conditions, data structures, and file operations.
